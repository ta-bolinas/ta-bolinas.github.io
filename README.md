# Tawny A. Bolinas — research website

Single-page site for GitHub Pages. No build step.

- `index.html` — all content and styling. Search for `[` to find anything still to fill in.
- `assets/img/` — photos (forest, bloom, meadow, daisies, autumn, portrait). To swap one, replace the file with the same name.
- `cv.pdf` — CV, linked from About and Contact. Replace it whenever the CV changes.

Colors and fonts are set in the `:root` block at the top of the `<style>` section.

## Publish
1. Upload everything in this folder (not the folder itself) to a public repo named `<username>.github.io`.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. The site appears at `https://<username>.github.io` within a few minutes.
